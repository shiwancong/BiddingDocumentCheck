# 准确性提升方案 - 100%准确率目标

## 核心策略

达到100%准确率需要采用**多轮验证 + 持续学习**的策略：

```
第一轮识别 → 自我验证 → 交叉验证 → 人工确认 → 知识库更新
     ↓            ↓           ↓           ↓           ↓
   85%        →    92%    →    96%    →   98%    →   100%
```

## 第一阶段：多轮验证机制

### 轮次1：初始识别
- 使用Claude AI进行初始识别
- 应用知识库规则
- 生成初版清单

### 轮次2：自我验证
AI自我检查清单：
- 检查是否有遗漏的废标关键词
- 验证每个条款的原文摘录是否完整
- 确认页码是否准确
- 检查逻辑解释是否清晰

### 轮次3：交叉验证
使用不同方法验证：
- 关键词扫描法
- 语义匹配法
- 表格结构分析
- 跨章节关联检查

### 轮次4：边界案例检查
专门检查容易出错的场景：
- 表格中的隐含条款
- 否定句+例外条件
- 跨章节的分散条款
- 反常识废标项

### 轮次5：完整性确认
最终确认清单：
- 所有明确废标条款是否已识别
- 所有表格是否已处理
- 所有附件是否已检查
- 所有跨章节引用是否已处理

## 第二阶段：知识库完善

### 1. 完善规则库

#### 新增：边界案例规则

```markdown
## 边界案例识别规则

### 案例1：隐含废标条款
**特征：** 没有明确"否决/无效"词，但暗示了后果
**模式：**
- "后果由...自行承担"
- "责任由...自负"
- "视为未提交"

### 案例2：表格中的隐含列
**特征：** 列名不明显，但内容包含后果
**检查方法：**
- 扫描所有表格
- 对每行内容进行语义分析
- 提取"要求+后果"结构

### 案例3：跨章节的时间条件
**特征：** 时间分散在不同章节
**处理方法：**
- 标记所有时间相关条款
- 查找关联的后果描述
- 合并成完整条款

### 案例4：附件引用的隐含要求
**特征：** "详见附件X"但没有明确后果
**处理方法：**
- 查找引用的附件
- 分析附件内容
- 提取其中的要求

### 案例5：否定+否定的双重否定
**特征：** "未...不..."
**模式：**
- "未按要求...视为无效"
- "未在规定时间...不予接受"

### 案例6：或逻辑的废标条件
**特征：** 多个条件满足任一即废标
**模式：**
- "A或B，其投标将被否决"
- "A、B、C任一不满足...无效"

### 案例7：递归引用
**特征：** 条款引用其他条款，其他条款又引用别处
**处理方法：**
- 跟踪引用链
- 合并所有相关内容
- 生成完整条款
```

### 2. 完善示例库

#### 新增：错题集

```markdown
## 错题集 - 历史错误案例

### 错误案例1：表格条款遗漏
**错误：** 未识别表格中的废标条款
**原因：** 表格列名不规范
**修正：** 检查所有表格的内容，不依赖列名
**学到的经验：** 不要仅依赖表头判断

### 错误案例2：跨章节条款未合并
**错误：** 将跨章节条款识别为多个独立条款
**原因：** 未跟踪引用关系
**修正：** 建立章节引用图谱
**学到的经验：** 注意"参见"、"详见"等引用词

### 错误案例3：原文摘录不完整
**错误：** 原文关键信息被截断
**原因：** 提取时只取了第一句
**修正：** 提取完整段落
**学到的经验：** 必须完整摘录，不能省略

### 错误案例4：分类错误
**错误：** 将时间方式分类为格式
**原因：** 只看关键词，未理解语义
**修正：** 综合分析语义
**学到的经验：** 分类要看整体含义
```
