# 核心识别规则（精简版）

## 废标条款核心关键词

### 直接废标词（必检）
- 否决、无效、不接受、拒绝、退回、不予受理
- 不进入评审、作无效处理、视为无效投标
- 磋商无效、响应无效、将被视为无效响应

### 强制性表述（需配合后果检查）
- 必须、应当、不得、严禁、务必
- 需（当后面有后果描述时）

## 9种条款类型（快速判断）

| 类型 | 关键特征 |
|------|---------|
| **资格** | 资质、证书、执照、许可证、业绩、人员 |
| **文件** | 附件、表格、清单、证明、材料 |
| **签字盖章** | 签字、盖章、签署、公章、法定代表人 |
| **时间方式** | 截止、递交、投标、开标、逾期 |
| **报价算术** | 报价、预算、限价、成本价、计算 |
| **响应性** | 响应、满足、符合、实质性、偏离 |
| **格式** | 装订、密封、页码、排版、字体 |
| **模板** | 指定格式、不得修改、格式模板 |
| **其他** | 无法归入上述类别 |

## 风险等级快速判断

| 等级 | 判断标准 |
|------|---------|
| **高** | 包含"否决"、"无效"、"不接受"等明确后果 |
| **中** | 包含"视为"、"按...处理"等条件式后果 |
| **低** | 格式要求、补充材料等软性要求 |

## 表格检查要点

1. **关键列名**：不满足后果、处理方式、评审结论
2. **注意**：逐个检查表格单元格，不要跳过
3. **区分**：功能要求表（技术指标）vs 废标条款表

## 特殊情况提示

- **跨章节**：注意"参见"、"详见"、"按...规定"
- **附件**：注意"附件X"、"格式模板"
- **反常识**：字体、文件大小、命名规则、扫描清晰度
