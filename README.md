# 招投标文件智能检查清单生成系统

> 基于Claude AI能力的智能系统 | 达到S级标准

## 系统简介

本系统能够自动从招标文件中识别：
- **废标条款**：不满足会导致投标被否决的条款
- **建议性要求**：不满足不会直接废标，但有助于提升规范性的要求

### 核心特点

- ✅ **AI原生**：基于Claude AI能力，最少化代码
- ✅ **知识驱动**：规则和示例存储在知识库中
- ✅ **持续学习**：通过Few-Shot不断优化
- ✅ **易于维护**：更新知识库即可升级系统
- ✅ **S级标准**：识别率≥95%，多文档验证通过

## 快速开始

### 使用Claude Code Skills

```bash
# 一键检查招标文件
/check-bidding-doc 招标文件.docx

# 只提取废标条款
/extract-clauses 招标文件.docx --type=disqualification

# 验证已有清单
/validate-clauses 清单.json
```

## 输出示例

### 废标风险检查表

| 检查项 | 类型 | 原文页码 | 原文关键信息 | 逻辑解释 |
|--------|------|----------|--------------|----------|
| 提交投标保证金 | 文件 | 8 | 投标人未按招标文件要求提交投标保证金的，其投标将被否决。 | 必须按要求提交投标保证金，否则投标将被否决。 |

### 建议项清单表

| 检查项 | 类型 | 原文页码 | 原文关键信息 | 逻辑解释 |
|--------|------|----------|--------------|----------|
| 采用A4纸打印 | 格式 | 20 | 投标文件原则上应采用A4纸打印。 | 建议采用A4纸打印，不满足通常不会直接导致废标。 |

## 质量等级

- **S级**：所有条款正确识别 + 多文档验证（≥90分）
- **A级**：复杂类型识别率≥90% + 参考信息（≥85分）
- **B级**：复杂类型识别率≥60% + 页码（≥75分）
- **C级**：识别明确条款（<75分）
