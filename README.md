# 招投标文件智能检查清单生成系统

> 基于Claude AI能力的智能系统 | S级标准（100%准确率）

## 系统简介

本系统能够自动从招标文件中识别：
- **废标条款**：不满足会导致投标被否决的条款
- **建议性要求**：不满足不会直接废标，但有助于提升规范性的要求

### S级标准（100%准确率）

| 要求项 | 说明 |
|--------|------|
| 质量等级 | S级（100%准确率） |
| 识别完整性 | 所有废标条款100%识别，无遗漏 |
| 参考信息 | 所有其他类型的废标条款都能提供参考页码和额外说明 |
| 分类准确性 | 每个条款的分类100%正确 |
| 原文摘录 | 原文关键信息100%完整摘录 |
| 验证机制 | 5轮验证确保100%覆盖 |

### 核心特点

- ✅ **AI原生**：完全基于Claude AI能力，零代码实现
- ✅ **知识驱动**：规则和示例存储在知识库中
- ✅ **100%准确率**：S级标准，确保无遗漏
- ✅ **完整参考信息**：所有条款都有参考页码和额外说明
- ✅ **易于维护**：更新知识库即可升级系统

### S级标准特点

与普通输出相比，S级标准输出包含：
- ✅ **完整的参考页码**：跨章节、附件引用等类型都标注了具体位置
- ✅ **详细的额外说明**：说明了条款类型、关联关系等
- ✅ **100%完整摘录**：原文关键信息无截断

## 质量等级

- **S级**：100%识别所有废标条款 + 完整参考页码和额外说明（90-100分）✅ **目标等级**
- **A级**：复杂类型识别率≥90% + 部分参考信息（85-89分）
- **B级**：复杂类型识别率≥60% + 页码（75-84分）
- **C级**：识别明确条款（<75分）

**S级标准详细评分**：
- 识别完整性（35分）：所有废标条款100%识别
- 分类准确性（20分）：每个条款100%正确
- 原文摘录（15分）：100%完整摘录
- 页码标注（10分）：100%准确
- 逻辑解释（10分）：100%清晰
- 参考信息（10分）：100%完整
