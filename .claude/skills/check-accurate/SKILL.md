# 高精度检查清单生成（S级标准 - 100%准确率）

## S级标准目标

通过5轮验证机制，确保达到以下标准：
- ✅ **100%识别率**：所有废标条款都能被正确识别（无遗漏）
- ✅ **完整参考信息**：所有其他类型的废标条款都能提供参考页码和额外说明
- ✅ **准确分类**：每个条款的分类100%正确
- ✅ **完整摘录**：原文关键信息100%完整摘录
- ✅ **清晰解释**：每个条款都有通俗易懂的逻辑解释
- ✅ **风险等级评估**：每个条款都有准确的风险等级（高/中/低）

## 废标条款核心分类（按PDF要求）

### 资格要求相关（高风险）
- 未提供企业营业执照
- 未提供资质证书
- 资质等级不符合要求
- 项目经理资格不符合要求
- 安全生产许可证过期/缺失
- 类似业绩不足

### 投标文件格式相关（高风险/中风险）
- 未按招标文件要求签署
- 未按招标文件要求盖章
- 投标文件密封不符合要求
- 投标文件格式不符合要求
- 缺少必要章节/内容

### 报价相关（高风险）
- 报价超过最高投标限价
- 报价低于成本且不能说明理由
- 报价有重大算术错误
- 提交备选投标方案

### 工期和质量要求（高风险）
- 工期不满足要求
- 质量标准不满足要求

### 其他要求（高风险/中风险）
- 投标保证金不足
- 投标保证金过期
- 联合体不符合要求
- 技术方案不满足要求

## 废标关键词全覆盖

必须搜索以下所有关键词（分组记忆）：

**第一组：否决类**
- 投标将被否决 / 否决其投标 / 磋商无效 / 响应无效

**第二组：无效类**
- 投标无效 / 视为无效投标 / 被认定为无效投标 / 作无效投标处理 / 作无效处理 / 将被视为无效响应

**第三组：拒绝类**
- 不予接受 / 将被拒绝 / 不予受理 / 将被退回

**第四组：排除类**
- 不进入评审 / 不得进入评审

## 5轮验证流程

### 第一轮：初始识别（全面扫描）

**目标**：确保不遗漏任何废标条款

**执行步骤**：
1. 解析文档结构（段落、表格、页码）
2. 逐段扫描，识别8种废标条款类型
3. 对每个表格的所有单元格进行语义分析
4. 查找所有附件引用和跨章节引用
5. 提取原文关键信息

**验证重点**：
- 是否扫描了所有段落？
- 是否检查了所有表格（每个单元格）？
- 是否检查了所有附件引用？
- 是否检查了跨章节引用？
- 是否搜索了所有4组废标关键词？

### 第二轮：完整性验证（确保无遗漏）

**目标**：确保100%覆盖所有废标条款

**验证内容**：

**关键词全覆盖扫描**：
- ✅ 搜索"否决"、"无效"、"不接受"、"拒绝"、"视为无效"、"作无效"等所有废标关键词
- ✅ 确认每个包含这些关键词的段落都被识别

**强制性和后果组合扫描**：
- ✅ 搜索"必须"、"应当"、"不得"、"严禁"等强制性表述
- ✅ 确认这些表述后是否有后果描述
- ✅ 如果有后果，确认为废标条款

**表格全覆盖扫描**：
- ✅ 逐个检查所有表格
- ✅ 对每个表格的所有单元格进行语义分析
- ✅ 区分功能要求表和废标条款表
- ✅ 提取"要求+后果"结构

**跨章节引用扫描**：
- ✅ 搜索"参见"、"详见"、"按...规定"、"按照..."等引用词
- ✅ 追踪每个引用到目标位置
- ✅ 合并跨章节的条款内容

### 第三轮：准确性验证（确保100%准确）

**目标**：确保每个识别的条款信息都准确

**验证内容**：
- 原文关键信息是否100%完整摘录（无截断）
- 页码是否100%准确
- 分类是否100%正确
- 逻辑解释是否通俗易懂

### 第四轮：参考信息验证（S级核心）

**目标**：确保所有需要参考信息的条款都有完整的参考页码和额外说明

**验证内容**：

**跨章节条款**：
- [ ] 是否提供了所有相关页码？
- [ ] 是否说明了跨章节关联关系？

**附件引用条款**：
- [ ] 是否提供了附件名称？
- [ ] 是否说明了附件的具体要求？

**反常识条款**：
- [ ] 是否提供了具体位置？
- [ ] 是否标注了"反常识项"？

**表格条款**：
- [ ] 是否提供了表格位置？
- [ ] 是否说明了具体行列？

### 第五轮：S级标准最终确认

**目标**：确认达到S级标准（100%准确率）

**确认清单**：

**识别完整性**（35分）：
- [ ] 所有废标条款100%识别，无遗漏
- [ ] 4组废标关键词全覆盖扫描完成

**分类准确性**（20分）：
- [ ] 每个条款的分类100%正确
- [ ] 9种检查项类型准确划分

**原文摘录**（15分）：
- [ ] 原文关键信息100%完整摘录

**页码标注**（10分）：
- [ ] 每个条款都有准确的页码

**逻辑解释**（10分）：
- [ ] 每个条款都有清晰的逻辑解释

**参考信息**（10分）：
- [ ] 所有需要参考信息的条款都有完整参考页码和额外说明

**风险等级评估**（额外加分项）：
- [ ] 每个条款都有准确的风险等级（高/中/低）

## 风险等级评估标准

| 风险等级 | 定义 | 判定标准 | 示例 |
|---------|------|---------|------|
| **高** | 违反直接导致废标，后果明确 | 包含"否决"、"无效"、"不接受"等明确后果词汇 | 资格不符、超限价、逾期 |
| **中** | 违反可能导致废标，需进一步判断 | 包含"视为"、"按...处理"等条件式后果 | 跨章节引用、附件引用 |
| **低** | 违反影响评审，但不一定废标 | 格式要求、补充材料等软性要求 | 字体、文件大小、装订 |

## 关键要点

1. **绝不假设**：不假设任何条款，全部验证
2. **穷尽扫描**：扫描所有内容，不遗漏任何地方
3. **多重验证**：每种方法都验证一遍
4. **交叉确认**：不同方法结果相互印证
5. **边界关注**：特别关注容易出错的边界情况
