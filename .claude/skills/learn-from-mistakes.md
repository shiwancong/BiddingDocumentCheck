# 从错误中学习 - 持续优化

## 功能说明

当发现识别错误时，使用此技能进行根因分析和知识库更新。

## 使用方法

### 方式1：对比学习

```
/learn-from-mistakes 原文件.md 正确清单.md
```

### 方式2：对话式学习

```
用户：系统识别的清单如下：[清单内容]
    正确的清单应该是：[正确内容]
    请分析差异并学习
```

## 分析流程

### 第一步：差异分析

对比系统识别结果和正确结果：

```markdown
## 差异分析

### 遗漏条款
| 条款内容 | 页码 | 遗漏原因分析 |
|---------|------|-------------|
| [内容] | [X] | [为什么遗漏] |

### 错误分类
| 条款内容 | 错误类型 | 正确分类 |
|---------|---------|---------|
| [内容] | 分类错误 → 正确分类 | |

### 页码错误
| 条款内容 | 错误页码 | 正确页码 |
|---------|---------|---------|
| [内容] | [X] → [Y] | |

### 摘录不完整
| 条款内容 | 问题 | 正确内容 |
|---------|------|---------|
| [内容] | 被截断 | [完整内容] |
```

### 第二步：根因分析

对每个错误进行深度分析：

```markdown
## 根因分析

### 遗漏原因分析

**表格条款遗漏**
- 原因：表格列名不规范
- 根本原因：只检查列名，未检查单元格内容
- 改进措施：扫描所有表格的所有单元格

**跨章节条款遗漏**
- 原因：未跟踪引用关系
- 根本原因：没有建立引用图谱
- 改进措施：建立章节引用索引

**隐含条款遗漏**
- 原因：缺少"否决/无效"关键词
- 根本原因：只依赖关键词匹配
- 改进措施：增加语义分析

### 分类错误原因

**语义理解错误**
- 原因：只看关键词，未理解语义
- 改进措施：综合分析整体含义

**上下文缺失**
- 原因：未查看相关段落
- 改进措施：扩大上下文窗口
```

### 第三步：知识库更新

根据分析结果，更新知识库：

```markdown
## 知识库更新

### 更新 data/knowledge/rules.md

### 新增规则：表格隐含条款识别
**识别方法：**
1. 扫描所有表格的所有单元格
2. 对每个单元格进行语义分析
3. 提取"要求+后果"结构
4. 如果单元格包含废标术语，提取整行

### 新增规则：跨章节引用跟踪
**识别方法：**
1. 扫描文档，提取所有引用标记
2. 建立引用索引图谱
3. 跟踪每条引用到目标位置
4. 合并引用内容和当前位置内容

### 更新 data/knowledge/examples.md

### 新增错题集：表格条款遗漏
**原文：** [具体表格内容]
**错误：** 未识别
**原因：** 表格列名不规范
**修正：** 检查所有单元格内容
**经验：** 不能只依赖表头，要检查内容

### 新增错题集：跨章节条款
**原文：** [分散在不同章节的内容]
**错误：** 识别为独立条款
**原因：** 未跟踪引用关系
**修正：** 建立引用图谱，合并内容
**经验：** 注意"参见"、"详见"等引用词
```

### 第四步：验证改进

重新处理同一文档，验证改进效果：

## 自动学习机制

```
┌─────────────────────────────────┐

└──────────────┬──────────────────┘
               ↓
┌─────────────────────────────────┐
│      分析模式和根因             │
└──────────────┬──────────────────┘
               ↓
┌─────────────────────────────────┐
│      更新知识库（规则+示例）     │
└──────────────┬──────────────────┘
               ↓
┌─────────────────────────────────┐
│      验证改进效果               │
└──────────────┬──────────────────┘
               ↓
         持续优化
```

### 自动触发条件

系统在以下情况自动触发学习：

1. **发现新的错误模式**
2. 识别率低于100%
3. 发现新的条款类型
4. 收集到一定数量的反馈

## 最佳实践

### 1. 定期学习

- 每周收集一次反馈
- 每月更新知识库
- 每季度全面审查

### 2. 案例积累

- 记录所有错误案例
- 分析错误模式
- 提取改进经验

### 3. A/B测试

- 新规则先小范围测试
- 对比新旧规则效果
- 确认后再全面应用

### 4. 持续监控

- 监控识别率趋势
- 监控准确率变化
- 及时发现问题
